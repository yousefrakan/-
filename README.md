# محرّر عروض الأسعار — مؤسسة المبيت للمقاولات العامة

موقع صفحة واحدة يطلّع عرض سعر بنفس ترويسة المؤسسة وتصميمها، ويحفظ العروض في أرشيف داخل المتصفح.
الترويسة والختم مستخرجين من ملف العرض الأصلي ومضمّنين داخل الملف نفسه — ما يحتاج أي صور أو إنترنت.

## الرفع على GitHub Pages

1. ادخل [github.com](https://github.com) وسوّي مستودع جديد (New repository)، سمّه مثلاً `quotations`، واختره **Public**.
2. اضغط **Add file → Upload files** وارفع ملف `index.html`.
3. اضغط **Commit changes**.
4. من **Settings → Pages**: في خانة *Source* اختر **Deploy from a branch**، والفرع `main` والمجلد `/ (root)`، ثم **Save**.
5. انتظر دقيقة، ويصير رابط موقعك:
   `https://اسم-حسابك.github.io/quotations/`

افتح الرابط من الجوال أو اللابتوب وضيفه للشاشة الرئيسية عشان يفتح مثل التطبيق.

## طريقة الاستخدام

- عبّي البيانات على اليمين، والمعاينة تتحدث مباشرة (في الجوال من تبويب «المعاينة»).
- اكتب `{المبلغ}` داخل نص العرض، والموقع يحطّ المبلغ بالأرقام والتفقيط بالحروف تلقائياً.
- جدول الصفحة الثانية: أضف البنود يدوياً أو بزر **«لصق من إكسل»** (انسخ ثلاثة أعمدة: النوع / العدد / الإجمالي).
- زر **«من الجدول»** ينقل مجموع الجدول إلى مبلغ الصفحة الأولى (قبل الضريبة أو شاملها).
- **حفظ في الأرشيف** يحفظ العرض، و**الأرشيف** يفتح العروض السابقة (فتح / نسخة جديدة / حذف).
- **طباعة / حفظ PDF**: اختر الوجهة «حفظ كـ PDF»، الهوامش «بلا / None»، وفعّل «الرسومات الخلفية / Background graphics».

## ملاحظات

- الأرشيف محفوظ في متصفح الجهاز نفسه. لنقله لجهاز ثاني: **الأرشيف → تنزيل نسخة احتياطية**، وفي الجهاز الثاني **استيراد نسخة**.
- رقم الحساب والآيبان وطريقة الدفع تنحفظ كإعدادات ثابتة وتجي جاهزة في كل عرض جديد.
- لتغيير الترويسة مستقبلاً: ابحث داخل `index.html` عن `class="bg"` واستبدل رابط الصورة.
